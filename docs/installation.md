# Installation Guide

## Quick Start (Docker)

```bash
git clone https://github.com/Gthruworldwide/odysseEG.git
cd odysseEG
cp .env.example .env
docker compose up -d
```

Open: http://localhost:7000

## System Requirements

- Docker 20.10+
- 4GB RAM
- 10GB storage

## Configuration

See `.env` file for all options:
- LLM configuration
- Database settings
- API keys
- Security options
